# v0.1.0-alpha.1

首次Windows Capture/PSpice统一MCP测试版；用于开发与用户试用并行。包版本0.1.0a1，Git tag v0.1.0-alpha.1。不是完整业务验收完成声明。

- 193个固定MCP工具，支持会话/副本/查询、属性与库编辑、部分放置/编号/连接对象，以及独立PSpice输入、任务、测量和模拟波形读取。
- 写操作默认在新副本完成，带plan、任务恢复、不确定写入不重放及保存重开校验。
- 同OLB独立封装家族与普通单元同schematic跨页补放已有原生/MCP证据；供电单元跨页VCC未连接的输出仍被拒绝。
- 完整绘图、层次/总线、原生DRC、Capture→PSpice端到端等仍未完成；具体见[测试指南](../testing/alpha-1.md)及[验收状态](../implementation/CURRENT-STATE.md)。

安装：下载Release中的Windows ZIP，按包内START-HERE.md创建独立Python环境并添加MCP客户端配置。ZIP包含wheel、固定依赖清单、配置示例与原创分压CIR；不包含Cadence程序、官方文档、许可证、DSN/OLB或本机私有验收数据。wheel自身为Python平台通用格式，运行环境限定Windows；本机只验证Cadence24.1。
