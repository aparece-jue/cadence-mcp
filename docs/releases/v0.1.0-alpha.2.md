# v0.1.0-alpha.2

Windows x64 / Cadence 24.1 的第二个固定测试版，Python 包版本 `0.1.0a2`，221 个结构化 MCP 工具。新增能力经过专项原生验证，但完整业务门禁仍为6/34；此版本用于用户试用与继续研发并行。

## 相对 alpha.1 的更新

- Capture 原生编辑布线后端：新增导线和 alias、指定重复层次的编辑实例、删除导线及关联 alias，保存后独立重开并核对显式连接预期。保护不相关导线的网络名；不把旧独立构造器或所有修改模式声明为已修复。
- 总线：受限竖直普通总线创建的计划/执行/任务/取消/恢复；查询总线、分支、入口及 `pin_member`。八位升序/降序、缺分支、脱离入口、原总线保持、八个真实引脚和原生成员位置均有正反例证据。命名网络的成员关系与入口实际接入分别报告，不以几何交叉推断电气连接。
- 宿主恢复：固定 Capture 编辑任务恢复原工程；真实写入完成后观察中断会保留围栏，恢复仅验证已有文件，不重复写入。已开始的宿主任务不能通过终止 Capture 取消。
- PSpice：原生 NET/ALS→profile→CIR 的受限任务和依赖准备、显式模型库的端到端参数迭代、官方 CLI 的字面参数 LIST 扫描及多块复数 DAT 读取/导出。独立引擎不支持该参数扫描时明确拒绝，须显式选择 CLI。
- 新增模型库检查、部分原生 DRC 报告解析和规则配置能力；接口存在不等于完整 DRC 自动执行验收通过。

## 安装与试用

下载本 Release 的 Windows ZIP，按 `START-HERE.md` 创建新的独立环境、安装固定依赖和 wheel。旧 alpha.1 保持不变，不覆盖旧环境或复用旧任务目录。依赖安装需要网络；本包不包含 Python、Cadence、许可证、官方手册或真实设计。

Capture 普通查询与独立 PSpice CLI 可先试用；原生编辑布线/总线及部分 Capture→PSpice 功能需要按指南显式配置现有单实例 Capture 桥接。客户端配置示例分开提供。正式参数以包内 `tools-contract.json` 为准。

## 已知限制

完整重复层次/flat 网络、嵌套 Bundle、部分跨页供电、缓存/字体/页面编辑、数字/混合 DAT、实际许可证失败分类及原生 DRC 完整自动闭环仍未完成。默认加密 nominal 模型的完整求解仍有限制；显式模型库通过案例不代表所有模型均可执行。PDF 自动打印延期，Allegro 排除。

回归与安装验收结果及校验值见 `release-manifest.json`、`SHA256SUMS.txt` 和仓库 `docs/releases/alpha-2-verification.json`。所有写入限定工作副本，未验证产物不能作为后续已验收输入。

## 本版安装复测注意事项

本次安装复测：官方 CLI 三个独立任务均超时；只读窗口列表确认 psp_cmd 正在 Cadence Product Choices 等待本机产品选择。没有修改许可配置，没有把超时认定为许可证失败。此版 CLI 安装复测未通过；已有此前专项通过记录不替代当前结果。请先在本机正常完成 Cadence 产品选择，再单独测试 CLI。独立 Tcl 引擎本次新 DC=2.5V 与 DAT 已通过；两后端不会自动切换。
