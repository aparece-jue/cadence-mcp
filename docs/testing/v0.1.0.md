# v0.1.0 安装

需要Windows x64、Python3.12+ x64、本机Cadence24.1与可用许可。解压到新目录（例如D:\cadence-mcp-v010），保留旧alpha环境。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-deps -r requirements.lock.txt
.\.venv\Scripts\python.exe -m pip install --no-deps .\cadence_mcp-0.1.0-py3-none-any.whl
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -c "import cadence_mcp; print(cadence_mcp.__version__)"
```

预期版本0.1.0。修改mcp-client.example.json的全部绝对路径，输入放inputs，输出使用新的workspaces；合并到所用MCP客户端并重启连接。推荐模块是cadence_mcp.validated_server，实际工具数65。不要沿用alpha的cadence_mcp.server配置，否则连接的是221工具开发入口。

先调用cadence_get_environment/runtime、cadence_get_capabilities，然后创建DSN工作副本，读取设计、属性及OLB。写属性需plan/apply/open_edit_result，所有源文件保持。

独立仿真使用pspice_prepare→pspice_plan_input_check/apply→pspice_plan_run/apply→pspice_open_run_dat，后端仅engine。随包divider.cir的DC目标为2.5V；输入检查仅parser/setup，不表示求解或电路安全。CLI和参数STEP不属于本版。

新增/删除导线与总线需一个干净的单DSN PCB测试宿主，并显式绑定guiSessionId/hostProject；按GUI-BRIDGE.md和随包辅助脚本设置，正常任务无需桌面点击。重复层次子页需要明确editorOccurrence；这只决定编辑上下文，不证明flat层次电气正确。开始后不可杀Capture取消，恢复只验证。

完整功能和边界请读SUPPORTED-FEATURES.md、tools-contract.json。1项文件symlink权限测试尚未验收；其他原34项保持开发进度。不要将连接表/几何建议当成原生DRC或完整设计通过。

已安装wheel不依赖研发源码。失败反馈请注明0.1.0、操作、工具、错误码及任务号，不上传真实工程、模型、许可或私有绑定。开发/alpha工具不属于本发行范围。
