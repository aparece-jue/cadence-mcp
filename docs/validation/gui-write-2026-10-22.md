## 失败保护与边界

- 写能力要求 `prepare_write_fixture.py` 新建副本及 `prepare_gui_bridge.py --allow-property-write` 显式准备绑定。默认绑定只有读取能力。
- 计划有效期约 55 秒；实际写入前检查文件指纹、旧值、generation、会话访问模式、clean 状态和请求截止时间。
- 写入发送前保存 started 日志并持有排他锁。写后断线、独立验证失败等不确定情况保留日志与锁，禁止自动重放，需人工调查恢复。
- 成功后的计划重放缓存仅保证同一 MCP 进程内；服务器重启后不会自动恢复或重放旧计划。
- 只验证定义级 pin-net 映射；没有验证 occurrence 展开的层次连接。没有开放位号、参数、元件或导线写入。
- 独立读取使用校验副本，避免依赖 GUI 文件占用状态；实际锁冲突并未得到证实。
