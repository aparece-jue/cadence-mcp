# 装饰线原生颜色

`capture_plan_graphic_line_add` 的可选 `lineColor` 接受已核实的原生 ColorT 码1..48，同时需要显式 `lineStyle` 和 `lineWidth`。1..47是调色板码，48是 DEFAULT_OBJECT_COLOR；49无效。此接口保存原生码，不定义 RGB 或保证显示/打印颜色。

写入仅发生在新 DSN 副本。DboLine 是矢量，颜色由其 `GetOwner` 返回的对象持有；通过官方 `DboGraphicObject_sSetColor/sGetColor` 访问，并设置/读取实例颜色。计划冻结目标页所有装饰线的几何、线型、宽度、实例色和定义色；重复几何仍按多重集合保留。保存后新进程逐项比较，返回 `nativeColorVerified=true`，不将几何相交当成电气连接。

省略颜色时沿用旧计划的参数、验证记录和结果范围。取消/幂等/恢复使用原装饰线任务族，恢复不重放写入。开发工具仍244，发行65工具契约保持，尚未晋级 alpha/release。

实际 MCP 对同一原副本连续添加颜色1、8、47、48，四次重开保留所有旧色记录，定义脚与连接不变，取消与新服务恢复通过。最早错页名及直接对 DboLine 调颜色方法的失败均保留，前者在计划前中止，后者在保存前中止。固定源与颜色预期指纹保持。已有线条更新/删除、其他图形/标题栏、字体/字形边界、occurrence 与原生 DRC 仍待独立验收。见 [批次172](implementation/batch-172-evidence.json)。

另外复验旧版不声明颜色的真实 MCP 任务：原两种线型的定义/实例默认色均为48，在该输出继续新增显式8色后，三条记录完整保持。旧调用的取消、幂等与新服务恢复仍通过。
