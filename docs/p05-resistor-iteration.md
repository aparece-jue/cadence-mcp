# P05 电阻参数迭代原生验收

本批完成一个原始P05实例的实际参数变化验收，尚未完成正式原生生成MCP任务封装。P05由planned推进为implemented_partial，不能计入完整通过。原默认加密库、折行引用、其余Capture/PSpice原34项条件保持不变。

## 已验收的完整来源链

1. 修改前冻结数学预期：R1从500Ω变为1kΩ，负载1kΩ、电容7uF；另一RL支路2H/1kΩ作为不应改变的控制。AC仍为100点、0.1到200Hz、幅度1V。RC预期为`1/(1+R1/1000+j*2*pi*f*R1*7e-6)`，RL为`1000/(1000+j*2*pi*f*2)`，首尾各两个节点共四个复数值；原容差不变。
2. 用现有MCP创建源DSN工作副本，准确定位R1，修改Value500→1k。原生保存、独立重开、完整定义/其他属性/连接保持验收通过；新服务器重开仍为1k，重复apply不再写入。电气行为没有由属性工具冒充认证，后续单独求解验证。
3. 在现有认证Capture宿主中分别为原基线和修改副本生成全新NET/ALS。活动工程及绑定保持、源DSN/OPJ不变，没有打开/切换GUI工程。两份NET仅R_R1数值不同，别名映射均与生成前冻结的7器件14引脚一致。
4. 为两套项目各自用原生CorSimSrvr生成新CIR。每套采用明确私有INI、原创未使用模型库、同源ALS引用和原profile；四文件准备闭包的每个源路径/hash均与NET/ALS/CIR/库角色对应。
5. 通过实际MCP执行两次官方CLI求解，每次都独立创建任务及OUT/DAT，四个复数值全部符合先前冻结的预期。低频RC输出实部约从0.666665V变为0.499998V；另一支路按原预期保持。CIR指纹、设计指纹、任务计划及DAT归属均不同且明确绑定。
6. 故意把修改前的DAT放入一个新的修改后任务：服务返回preexisting_cli_output，求解器未启动，原旧DAT未被覆盖。新干净任务才执行正例。新的MCP服务器重复apply两个已完成任务，结果完全相同，所有任务文件和账本字节不变。

参数化公开脚本在另一套全新目录重复生成/求解后，再次通过完整链审计。原安装、真实设计和发布alpha.1均未改变。核心模块未改，本批不重复完整回归；最近核心回归沿用第103批595项，594通过/1原权限skip。真实原生/MCP新增验收与主机回归分别记录。

## 导出前置条件与保留失败

直接给修改产物`design.dsn`调用原生导出，接口返回0、输出空NET，日志ORNET1165表示无法初始化PSpice explorer。保留失败。给同字节DSN配齐同名OPJ及对应profile后，接口返回1并生成新NET/ALS；无需初始化其他应用对象，也无需GUI切换。受控导出脚本现在先检查同名OPJ，裸DSN在派发前拒绝。这个证据只证明当前24.1上下文，不把旧ProjectVersion字段当作运行版本。

参数化审计脚本先后因参数变量与比较文本变量重名、第一次修复替换过宽而失败。两次脚本失败保留，新目录修复后只重新审计已完成任务，未放宽预期、未重跑求解器。原生业务正例不受这两次脚本错误影响。

## 可公开复现材料

- `tools/smoke_lowpass_resistor_edit.py`：准确源指纹的既有私有LowPassFilters fixture，先冻结预期，再用MCP改Value及重开。
- `tools/probe_bound_project_copy_netlist.py`：绑定已有Capture宿主和不同私有项目副本，固定NET/ALS导出；同名OPJ、源revision、活动上下文与源文件检查；无任意Tcl接口。
- `tools/prepare_lowpass_iteration_inputs.py`：从两份已审计项目及NET/ALS生成明确私有配置下的原生CIR。
- `tools/smoke_lowpass_parameter_cycle.py`：真实MCP两次求解、原预期及旧DAT拒绝。
- `tools/audit_lowpass_parameter_cycle.py`：设计→NET/ALS→CIR→四文件闭包→计划→DAT逐项审计，以及新服务器幂等。

路径均通过命令行提供，`--help`列出参数；首次源指纹固定到原本机私有fixture，不要求安装内任意示例具有同字节。公开的预期JSON是自主数学计算，不包含DSN/OPJ/官方模型或原生输出。原始实验与回执保留于.local，公开指纹与摘要见batch-104-evidence.json。

剩余工作是正式MCP原生生成任务、它们的持久计划/取消/恢复/来源与错误边界，以及原V04/P04等联合门禁。下一步实施契约见设计文档08，不由脚本正例宣称所有业务完成。
